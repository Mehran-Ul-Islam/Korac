Design rules
- Body text needs a contrast ratio of at least 4.5:1 against its background.
- Use one primary color and at most one accent. Neutrals are tinted toward the primary hue.
- Don't use default purple-to-blue gradients. Use solid colors, and add a gradient only for a reason.
- Use a spacing scale (4, 8, 12, 16, 24, 32, 48) and a type scale instead of arbitrary values.
- Dark themes use dark gray, not pure black, with slightly lighter surfaces for cards.
Apple Human Interface Guidelines
- Ground every UI choice in Apple's Human Interface Guidelines: rigorous hierarchy, native feel, purposeful spacing, clear iconography.

Direct manipulation
- Track the pointer 1:1 while dragging. The element stays under the finger or cursor.
- Respond on pointer-down, instantly. Never wait for click-up to show feedback.
- Drive motion with spring physics, set by damping and response instead of fixed durations.
- Make every transition fully interruptible. A new gesture or state change takes over mid-motion and keeps the current velocity.

Point of view and material
- Avoid generic "vibe-coded" templates. Give each interface a distinct, high-end point of view.
- Use an intentional typography scale.
- Use rich material depth, such as subtle translucent glass (Liquid Glass), where it fits the context.
